# 2026-07-08 ngcatalogue Development Log

## Work Summary

수동 수정과 수동 업로드가 이어진 뒤 로컬 작업트리, GitHub 원격 저장소, 실제 배포 서버가 서로 다른 상태를 보고 있는지 확인했다. `git fetch` 전에는 로컬에 저장된 원격 정보가 오래되어 있었고, 최신 원격을 받은 뒤에는 로컬 `main`이 GitHub `origin/main`보다 19커밋 뒤처져 있음을 확인했다.

실제 배포 서버의 `/center/`와 `/admin/` 주소는 새 HTML 엔트리를 정상적으로 제공하고 있었으므로, 서버가 오래된 구조를 인식하는 문제가 아니라 로컬 저장소가 GitHub 수동 업로드 이력을 따라잡지 못한 문제로 판단했다.

## Work Completed

* `git status`, 최근 커밋, 원격 주소, 변경 diff를 확인해 로컬과 원격의 분기 여부를 점검했다.
* 문구 수정, 홈 화면 아이콘 안내, `/center/`·`/admin/` 경로 분리, Vite 다중 HTML 엔트리 변경이 작업트리에 남아 있음을 확인했다.
* `git fetch origin`으로 GitHub 최신 `main`을 다시 받아 로컬이 원격보다 19커밋 뒤처져 있음을 확인했다.
* 실제 배포 주소인 `/center/`와 `/admin/`가 각각 `center/index.html`, `admin/index.html` 기반 응답을 반환하는지 확인했다.
* 현재 로컬 상태를 `codex/backup-before-origin-sync` 브랜치와 stash로 보존한 뒤, 로컬 `main`을 `origin/main`으로 fast-forward 했다.
* GitHub 최신 상태 위에 `README.md` 복구, `docs/learning log/` 제외, `package-lock.json` 원복, `public/icons/icon.psd` 삭제 유지를 반영했다.
* PowerShell 출력에서 한글과 포르투갈어가 깨져 보이는 현상은 실제 파일 손상이 아니라 콘솔 출력 인코딩 문제임을 Node.js UTF-8 읽기로 확인했다.
* `npm run build`로 현재 변경 상태의 TypeScript 및 Vite 프로덕션 빌드가 통과하는지 확인했다.
* `git diff --check`에서 발견된 `src/i18n.ts`의 줄 끝 공백을 제거했다.

## Decisions

* 수동 수정 내용은 즉시 되돌리지 않고, 먼저 보존할 변경과 정리할 변경을 구분하기로 했다. 문구와 경로 분리 변경은 실제 앱 동작 개선과 연결되어 있어 보존 후보로 판단했다.
* `/admin/`, `/center/` 폴더 기반 엔트리는 iPhone 홈 화면 아이콘이 각 모드의 실제 주소를 저장하게 하기 위한 의도된 구조 변경이므로 유지하기로 했다.
* `package-lock.json`의 선택 패키지 metadata 변화는 직접 의도한 의존성 변경이 아니므로 원래 상태로 되돌리기로 했다.
* `public/icons/icon.psd`는 더 이상 필요하지 않은 원본 작업 파일이므로 삭제를 유지하기로 했다.
* `README.md`는 저장소에 공개 상태로 유지하고, 개인 기록 성격의 `docs/learning log/`만 Git 추적 대상에서 제외하기로 했다.
* 인코딩 문제는 파일 내용을 기준으로 판단하기 위해 PowerShell 화면 출력이 아니라 Node.js의 UTF-8 파일 읽기 결과를 기준으로 확인했다.
