# 2026-07-04 NG Catalogue Development Log

## Work Summary

GitHub Pages 배포 환경에서 해시 라우트 `#/catalog/center`로 진입해도 공개 카탈로그 모드가 유지되어 공개 가격 컬럼만 보이는 문제를 수정했다. 라우트 판별을 `window.location.hash`까지 반영하도록 바꾸고, 센터 상품 로딩 실패 시 공개 상품 목록처럼 보이는 화면으로 진행하지 않도록 센터 전용 오류 화면을 먼저 표시하게 했다.

* 컬럼 설정은 기존 `columnConfig[mode]` 사용 구조를 유지했다. 라우트 모드만 정확히 전달되면 데스크톱 테이블, 모바일 카드, 인쇄 스타일이 같은 모드 기준을 공유하기 때문이다.

## Decisions - Pack Quantity Badges

* 수량 표시는 `memo`에서 파싱하지 않고 `pack_quantity`만 신뢰하기로 했다. 데이터 마이그레이션이 이미 끝났고, 화면이 메모 형식에 다시 의존하면 이후 메모 문구 변경에 취약해지기 때문이다.
* 세트 배지와 수량 배지는 한 컴포넌트에서 함께 배치하되 조건은 독립적으로 유지했다. 그래서 세트 상품이 아니어도 수량 배지가 나올 수 있고, 세트 상품이면서 묶음 수량이 있으면 `[Conjunto] [4 ea]` 형태가 자연스럽게 유지된다.
* 검색과 정렬 로직에는 `pack_quantity`를 추가하지 않았다. 요청 범위가 상품명 옆 표시와 API 응답 확장이었고, 기존 검색/정렬 기준을 바꾸면 사용자가 보던 결과 순서가 달라질 수 있기 때문이다.

## Decisions - Center Table Scroll Layout

* 인쇄에서는 sticky와 내부 스크롤을 모두 끄기로 했다. 인쇄 시에는 화면 조작성이 아니라 전체 데이터가 끊기지 않고 배치되는 것이 더 중요하기 때문이다.
